# iA Vende

Sitio comercial de iA Vende.

## Objetivo
Convertir tráfico en diagnósticos comerciales y conversaciones calificadas sin depender de infraestructura pagada.

## Funnel
Contenido -> Diagnóstico de Conversión con IA -> WhatsApp -> Sprint de Conversión -> Implementación.

## Publicación
El repositorio incluye un flujo oficial de GitHub Pages. En GitHub, activar una sola vez:
Settings -> Pages -> Build and deployment -> Source: GitHub Actions.

Después, cada cambio en master se publica automáticamente.

## Dominio
Cuando iavende.com esté listo para apuntar a GitHub Pages, configurar el dominio desde Settings -> Pages sin modificar registros MX/TXT de correo.
